# POINTWORLD — панель управления ботами

Тёмная одностраничная панель: **BLACK LIST** (30 ботов, кнопка «ПРИНЯТЬ») и
**WHITE LIST** (принятые боты, кнопка «КИК», кнопки «ХОДИТЬ/СТОП», чат).

Всё работает в облаке на Render.com — ваш компьютер можно выключить.
Каждый принятый бот сам подключается к серверу `PointWorld.aternos.me:49528`
и ходит + прыгает на спавне.

---

## Как работает авторизация ботов

- Первый заход бота на сервер: бот сам отправляет `/reg mamba_1234 mamba_1234`.
- Все последующие заходы: бот сам отправляет `/l mamba_1234`.
- Нужно только один раз запустить сервер в панели Aternos — дальше боты подключаются сами.

Важно: Aternos сам выключает пустой сервер через ~5 минут. Пока хотя бы один
бот онлайн, сервер живёт. Если сервер выключился — запустите его на
aternos.org, и все боты из White List автоматически зайдут через 1–3 минуты.
Для полностью автономного 24/7 сервера используйте exaroton.com (платные
кредиты) — там есть keep-alive.

## Деплой на Render (один раз, ~10 минут)

1. Заведите аккаунт на https://github.com
2. Создайте репозиторий: **New repo** → например `pointworld-bot-panel` → Public.
3. В репозитории нажмите **Add file → Upload files** и загрузите все файлы
   проекта (package.json, render.yaml, src/, public/, scripts/, .gitignore),
   затем **Commit changes**.
4. Заведите аккаунт на https://render.com — вход через GitHub.
5. Render Dashboard → **New + → Blueprint** → выберите репозиторий →
   **Apply / Create**. Настройки возьмутся из `render.yaml`.
6. Дождитесь статуса **Live** (2–4 минуты) — готово, адрес вида
   `https://pointworld-bot-panel.onrender.com`.

Компьютер можно выключать. Панель сама пингует себя и не засыпает.

## Использование

- **BLACK LIST** — список всех 30 ботов. «ПРИНЯТЬ» → бот переходит в White List
  и заходит на сервер (сам регистрируется/логинится) и начинает ходить и прыгать.
- **WHITE LIST** — принятые боты. Клик по нику открывает управление:
  - «ХОДИТЬ» / «СТОП» — движение бота;
  - чат справа — сообщения сервера и малый ввод: можно писать от имени бота;
  - «КИК» — бот отключается и возвращается в Black List.
- Слоты на бесплатном Render — **8 ботов одновременно** (лимит по памяти).
  Остальные принятые ждут в очереди. Лимит меняется переменной `MAX_ONLINE`.

## Локальный запуск (не обязательно)

```
npm install
npm start
```
Открыть http://localhost:3000

## Настройка (файл src/config.js или переменные окружения)

| Переменная   | По умолчанию              | Смысл                      |
|--------------|---------------------------|----------------------------|
| MC_HOST      | PointWorld.aternos.me     | адрес сервера              |
| MC_PORT      | 49528                     | порт                       |
| MC_PASSWORD  | mamba_1234                | пароль /reg и /l           |
| MAX_ONLINE   | 8                         | ботов одновременно         |

Список ников — массив `NICKNAMES` в `src/config.js`.

## Важно

Панель в открытом доступе: любой, у кого есть ссылка, может кикать ботов.
Render не даёт кнопки «сделать приватным» — при желании добавьте basic auth.

Mineflayer-боты — это «необычный» трафик для Aternos: формально их использование
может не нравиться правилам Aternos, используйте на свой риск.
